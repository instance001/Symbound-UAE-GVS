UAE (Universal Analogy Engine) and GVS (Global Vector Sweep) define a structured reasoning protocol with:

Bounded determinism: fixed analogical rules where the implementation defines them.
Non-agency: no autonomous hypothesis ownership or independent scientific authority.
Property-driven mapping.
Cross-domain expansion.
Value-scoring.
Commons-locked outputs.

The system reorganizes existing knowledge using structural analogy and property mapping. It can surface candidate mechanisms or analogies for humans to assess, but it does not validate new science by itself. Outputs are intended as commons-governed artifacts under AGPLv3 + Symbound Addendum.
